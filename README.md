# Employee Salary Analysis - Micro Project

## 📌 Project Overview
This project is a Python-based micro project that generates, analyzes, and visualizes synthetic employee salary data. It explores the relationship between departments, years of experience, and salaries using standard data science libraries.

## 🚀 Features
* **Data Generation:** Creates a synthetic dataset of 60 employees with randomized attributes including Department, Gender, and Experience (1 to 20 years).
* **Salary Calculation:** Computes salaries based on departmental base pay (e.g., HR: 25000, IT: 40000) plus an experience multiplier (Rs. 1800 per year) and random variance.
* **Statistical Analysis:** Uses NumPy and Pandas to calculate mean, median, standard deviation, and correlations between experience and salary.
* **Data Categorization:** Segments employees into "High" (>= 60000), "Medium" (>= 45000), and "Low" salary tiers[cite: 1].
* **Data Visualization:** Automatically generates and saves four analytical charts to the local directory[cite: 1].
